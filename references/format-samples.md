# 正式输出格式样例

本文件只演示排版，不提供项目事实或默认风格；括号内容实际使用时必须替换。主定义在[提示词写作](prompt-writing.md)，时长/收尾见[时长与连续性](continuity-and-duration.md)，旧收尾入口[segment-ending.md](segment-ending.md)仅作兼容索引。

## 用户可见顺序

默认聊天完整交付如下；用户只要文件或正文时按指定载体与范围交付。每个独立生成任务一个单元：全局画面与声音、实际素材完整绑定、按成片顺序排列的镜头。段间两个空行，即三个换行；正文无栏目、子段、校对话术或默认时间码。批量授权可交多个完整单元。

## 文戏示例

示例假设甲、乙对白及全部动作都有当前权威依据，音色已实际提供，且本段是同场第二段、上一段的位置截图已提供。它不是可原样提交的项目正文。

```text
（创作者明确提出的导演或作品参考，没有就不写），（用户已确认且本段需执行的画面、光线与表演特征），（本片确认的正向画质词），（本片确认的排除词），无BGM，无音乐，无字幕，不出现包装，仅音效。


院落参考@院落.png，甲参考@甲.png，乙参考@乙.png（角色位置空间关系参考@1-1-1截图.png）。甲音色参考@甲音色.mp3，乙音色参考@乙音色.mp3。


50mm平视双人中景，甲在画面左侧，走进院门；乙在画面右侧，站在檐下，两人相对。


50mm过肩人物关系中景，甲停下，说：“（甲的权威对白）”


85mm过肩人物关系近景，乙站在原地，等待。


85mm过肩人物关系近景，乙看着甲，回答：“（乙的权威对白）”
```

第一镜写清谁在画面左侧、谁在画面右侧。换说话人换镜，同一人的同轮连续发言不机械拆句；一个镜头只做一件事，听者反应单独成镜，写简单。过肩镜不另写前景是谁；正文不写声音描写，台词除外。人物姓名不插入固定关系镜头句式内部；已确认无音色则删除相应音频绑定，无实际素材则整段省略，不能保留占位名；一场的第一段没有上一段截图，不写空间关系参考。

## 动作戏示例

示例中的发射、受击、零件脱落和倾倒仅在当前权威明确时可写，不从示例带入其他设备或赛事。

```text
（创作者明确提出的导演或作品参考，没有就不写），（用户已确认且本段需执行的动作场面视觉特征），（本片确认的正向画质词），（本片确认的排除词），无BGM，无音乐，无字幕，不出现包装，仅音效。


赛场参考@赛场.png，红方机器人参考@红方机器人.png，蓝方机器人参考@蓝方机器人.png。


红方机器人从画面左侧、蓝方机器人从画面右侧相向推进，高速侧向跟随红方机器人压过地面接缝，云台转向并发射；切入弹丸命中蓝方装甲。


机器人机身视角突然偏转，受击部位崩裂。


慢镜头呈现受损机器人失衡倾倒，零件依照重量和惯性落下，机身触地。
```

动作戏不强迫焦段前缀，第一镜交代各方起始位置和方向；正文不写碰撞声、爆炸声等声音描写。慢镜头须按实际容量采用；不能把本例所有内容硬塞入某个数字，或追加无功能的一秒全景。

## 单元外说明

```text
整场预计时长：约X—Y秒（当前权威整场总量）。
本段预计时长：约A—B秒。
本段结束点：（完整动作/对白/情绪落点）。
下一起点：（场次/分段＋第一项未写权威动作＋开场连续状态；本场已完则如实说明）。
截图提醒：（同场还有下一段时，请生成后截一张能看清角色位置和空间关系的画面，命名为约定的截图名；下一段换场则说明无需截图）。
```

时长来自预检与复核，不倒填；未指定时默认30秒一段。正文按指定载体完整交付，四项状态和截图提醒依主规则按需简报，不把示例说明强加给只要正文/文件或状态不变的小修。
