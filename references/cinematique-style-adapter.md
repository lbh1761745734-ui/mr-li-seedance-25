# 剧本驱动的审美推荐与 Cinematique 适配

首次需要推荐/自定义美术方向，或用户要求使用本库时，连同[视觉基调](visual-baseline-and-tags.md)读取。本模块补选择和转写方法；权威、容量、声音、资产、采用、连续性与正式排版仍由既有主要模块定义。方向已确认且没有相关变化时直接继承，不每段重新检索全库。

## 从剧本筛选

先读当前授权范围完整原文，区分剧本事实、用户确认、助手推断与必要缺口；推断不因记入状态就成为年代、阶层、服装或地点事实。用一句人话说明当前戏主要让观众读取什么：关系、行动、空间、线索或感受。按媒介、实际日夜/光源、身份造型、当前画幅和原剧情作硬筛，再按剧情功能、可见差别和已定偏好选2—3个候选。

候选来自下述原创知识卡或当前实际参考。名字、器材、软件和提示词长度不作质量排名。一个主导方向配少量辅助特征，不把全库好词混搭；用不同取景强调疏离时保留原站位与动作。用户已明确让执行者代选时，在其范围内选择、说明理由并记录，不为该决定重复索权；仅“不确定”或多个方案后的“继续”不视为代选。

## 给小白的候选成果

选项按[七步引导](guided-production.md)的选项规则给出：有助手自带的选项控件就用，没有就用文字选项；A、B 给两个剧本驱动的具体方向，C 明确为“自定义”，接受用户自然语言、作品或图片参考，不放第三个预设风格。每个推荐方向先用短文字给人话名称、一句观众感受、与当前原文相连的推荐理由、3—5个可观察特征、可核对来源/参考用途和一个主要代价，再给选项。来源链接指向模板时说明是模板描述；原站生成例图不能冒充官方剧照。尚未打开的图片只作为检索入口，不能说已目视确认其光色或服装。

只补会影响当前结果的1—3个未知项，不要求用户学术语或逐一填写927肖像选项。用户已选一张覆盖媒介、光色、构图和表演的卡，只补缺失的画幅等；不重问整套。允许“更亲近”“别太像广告”“更冷一点”等表达，先指出实际可见差别，再调整相应轴；不能借气质改脸、年龄、阶层或剧情。

先用当前剧情解释方向差别，不把“选项”理解为三分比较图，不因用户授权制作后续资产就抢先生成风格小样。仅在用户另外要求比较小样时实际生成：人物身份、已确认服装、场景事实、动作站位、画幅与时长保持一致；图片是辅助参考，仍由选项决定。看不出差别就只比较一个轴；都不喜欢先找到最不喜欢的部分，再保留其他决定重做候选。小样可选，不阻塞已确认基调下的提示词。审美基线确认与生成结果采用是两次不同状态。

## 四栏目转成实际执行层

不要只把原站①②③④换成三个段落；各栏目会混入事实和冲突。先建立短中间记录，再写正式正文：

| 来源内容 | 当前归属与处理 |
| --- | --- |
| 美学锚点/作品与作者 | 选择与来源记录；正文只留已确认的可见特征 |
| 质感/镜头感 | 稳定清晰度、纹理与高光入全局；景别、机位、运动、移焦按镜头功能使用；品牌不承诺物理复现 |
| 光影/色彩 | 区分场次日夜、天气、地点、实际光源等事实与审美选择；栏名不能给事实授权 |
| 主体/构图/情绪 | 当前人物、动作、关系、服装、道具取自当前依据；构图适配观看任务，原例表演不自动成为剧情 |
| 画幅、平台参数、占位符、复制尾串 | 本轮实际工具设置或来源噪声；不能默认21:9、保留空参数或虚构绑定 |

来源事实只按获准用途继承；用户明确拿图定服装、身份、场景或构图时保留其能证明内容，光色参考里的演员、车辆、道具、剧情和音乐不自动迁入。已确认基调保存强度、适用集场段、例外与成片/母资产阶段；当场事实、画幅、运动和实际终态另记，见[项目上下文](context-protocol.md)。

转写名词时核对动作所作用的实体与层级：整体、部件和内部结构不能互相代替；术语不确定时回看当前原文或实际参考。氛围词不能改写物体状态或增加光源。来源与结果有冲突时按当前制作权威返工，不反过来把生成图的偶然内容写成剧本事实。

摄影机运动330条和组合器228条的UI被统一追加去高频/保持线色亮度/ARRI65与Cooke尾串，共558条；这不是每个技法的定义，应从独立参数来源提取。Whip Pan、Two-Shot、Three-Shot、Lead Room、In Medias Res分别为甩镜、双人镜头、三人镜头、视线/运动留空、从故事中段开场，不沿用机译错误。同名图与视频逐条查动作、道具、服装与空间，不默认内容一致。

单镜先定主导运动，区分移动、摇摄、变焦、移焦；复合动作写先后与落点。固定/推近、全清楚/浅景深、高反差/抬黑、黑白/强彩色及日夜光源冲突先解决。类型、特效和叙事结构参考不授权改故事。母资产干净、稳定、可复用；最终颗粒或旧化只用于已确认区域/阶段。

## 写作、实际结果与回退

选择完成后依[提示词写作](prompt-writing.md)写全局、实际素材绑定、镜头自然段；原站四栏目、来源名、内部记录和平台尾串不进入正文；创作者自己明确提出参考的导演或作品除外，按提示词写作的全局段结构写。只从权威原文继承对白、所有原动作与因果，完整保留原有容量、关系镜头、说话人切镜、声音原句、双空行和首尾状态规则。当前已确认特征仍完整执行，不能缩成泛泛“电影感”。

用户授权的代表镜头/场次实际生成后，分别核对事实身份、审美是否落实、动作对白、连续性和技术质量。未落实属于执行返工，目标已落实但用户不喜欢才改相关审美选择；平台失败属于技术问题。按[结果返工](result-repair.md)保留其他已采用内容和历史，仅更新受影响轴、范围及副本，不重走七步，不把生成/自检自动记为采用。
