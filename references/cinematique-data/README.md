# cinematique-data（开源版未附带）

这里原本放的是电影美学知识库的数据文件（6 个 JSON，共 2733 条来源条目、2463 条剧照元数据等），
文本快照来自 [MOKE Cinematique](https://www.mokeaigc.ai/cinematique.html)。

这部分数据的权利属于原作者，开源版暂不随仓库分发。获得授权后，把以下文件放回本目录即可启用检索：

- aesthetics.json
- cinematic-technique.json
- assets-portraits.json
- source-index-2733.json
- film-index-127.json
- still-metadata-2463.json

没有这些数据时，Skill 的其余功能照常使用；定风格这一步会只按剧本和视觉基调规则给出 A/B 方向。
