# 李先生AI影视全流程Skill（mr-li-seedance-25）

把传统剧组的规矩交给 AI。当前版本 2.4.1。

这个 Skill 用在影视制作的执行期。剧本定稿以后，它带着你一步步往下做：锁定剧本、定风格、做人物和场景的素材、写每一段的视频提示词，再到生成平台上把节点建好，生成完不满意就返工修改。配乐、字幕和包装都不放进生成画面里，留给后期去做。

为什么要做它？用 AI 拍片的人大多遇到过这些麻烦：一段视频只能生成十几秒，模型又记不住上一段，人物经常换了脸、换了衣服；让 AI 帮忙写提示词，它会擅自改台词、加戏；素材没有统一的样式，拍到后面几集就对不上了；一个地方出错，整段都得重来，积分烧得很快。新手往往说不清自己想要什么风格，做了多年传统影视的人，经验也很难直接用到 AI 上。

所以它用传统剧组的方式来组织工作：创作者是导演，AI 是守规矩的副导演和场记，生成平台就是摄影机。剧本说了算，一个字都不改；按演员真实的表演时长来切段，每一段都带齐自己需要的素材；AI 只负责把节点建好，按下生成键的永远是创作者自己。这些规矩来自主创七年的片场经验，在《左柳清风》《铁甲青春》《我在非洲种水稻》里一条条磨出来，不绑定任何平台和模型。

## 安装

最简单的方法：下载本仓库的 zip，拖给你的 AI 助手（Codex、Claude、DeepSeek Harness 等能读取 Skill 的助手），说一句：

> 帮我安装这个 skill

其他安装方式和自检命令见 [INSTALL.md](INSTALL.md)，第一次使用看 [GETTING_STARTED.md](GETTING_STARTED.md)。安装与自检需要 Python 3.9 及以上。

## 关于电影美学知识库

Skill 的风格推荐可以检索一份电影美学知识库，文本快照来自 [MOKE Cinematique](https://www.mokeaigc.ai/cinematique.html)。这部分数据的权利属于原作者，开源版没有附带，详见 [references/cinematique-data/README.md](references/cinematique-data/README.md)。没有数据时，其余功能照常使用。
